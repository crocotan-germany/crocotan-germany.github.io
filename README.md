# Crocotan Germany

This repository hosts the static website for Crocotan Germany on GitHub Pages.

## Contents

- `index.html` — landing page for the site
- `assets/` — static assets such as styles, scripts, and images
- `README.md` — project overview and usage notes

## Local preview

You can preview the site locally by serving the repository folder with a simple web server:

```bash
python -m http.server 8000
```


## Deployment

This project is configured for GitHub Pages. Pushing updates to the default branch will publish the website automatically.
